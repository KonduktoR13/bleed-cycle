# Тихий цикл

Приватная PWA для мужа: модель эмоционального фона жены, stats и подсказки по общению. https://konduktor13.github.io/bleed-cycle/

История хранится в браузере под прежним ключом `bleed-cycle-pwa-v1`. JSON и скриншоты пользователей не входят в публикацию.

Запуск: `python3 start_server.py`. Для установки PWA нужен HTTPS или localhost; обычный HTTP в локальной сети не обеспечивает установку и офлайн-режим.

Проверки:

```bash
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

Браузерные проверки включают мобильный интерфейс, импорт, запись окончания, оценки и заметки дневника, настройки, работу офлайн и миграцию установленных v22/v23/v24 на текущую версию с сохранением истории. Фикстуры синтетические. Можно дополнительно проверить локальный экспорт через переменную `PRIVATE_BACKUP=/path/to/backup.json`; файл не копируется в проект.

Публикация после коммита и отправки `main`:

```bash
python3 scripts/publish.py
```

Сайт развёртывается GitHub Pages из ветки `gh-pages`. Скрипт проверяет тесты и копирует только явно перечисленные файлы приложения из коммита, затем отправляет отдельный коммит в `gh-pages`. Не использует принудительный push. После публикации следует проверить статус GitHub Pages и файлы на публичном URL.

Версия v25 согласована в `app.js`, `index.html`, `service-worker.js` и `package.json`. При следующем выпуске нужно обновлять номер кэша и ссылки на CSS/JS вместе. Service worker устанавливает полную версию атомарно, сохраняет её офлайн и удаляет только старые кэши этого приложения. Проверка обновлений происходит при открытии, возврате в приложение и раз в час на открытом экране. Во время открытой формы перезагрузка откладывается; появляется кнопка «Обновить».

Модель использует последние подходящие интервалы между началами и даты окончания. Прогнозные даты не становятся записями; диапазон дат является эвристическим ориентиром, а не проверенным доверительным интервалом. При пропущенном начале или длинном промежутке фазу нельзя уверенно восстановить. Эмоциональные шкалы иллюстрируют общую модель и не предсказывают личное состояние.

Обзор источников, границы модели и воспроизводимая симуляция адаптации: [проверка v24](docs/review-v24.md).

Основная модель и повторная проверка психологических/поведенческих исследований: [research-v25.md](docs/research-v25.md). Эмоциональные показатели доступны сразу; личные поправки появляются после достаточного числа наблюдений.
